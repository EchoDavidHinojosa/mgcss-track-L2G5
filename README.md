## Descripción

Este es el proyecto de la asignatura Mantenimiento y Gestión del Cambio en Sistemas Software. Consiste en un backend para gestionar solicitudes técnicas: crear solicitudes, asignar técnicos, cambiar estados y reabrir solicitudes cerradas.

El desarrollo ha seguido principios de Domain-Driven Design, TDD y calidad estática con pipelines CI/CD.

**Autores:** David Hinojosa (EchoDavidHinojosa) y Youssef18sa
